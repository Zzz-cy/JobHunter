## 映射方案

### 📁 `api/` → `app/api/`

| `llm_module` 文件         | 目标位置              | 说明                                                  |
| ------------------------- | --------------------- | ----------------------------------------------------- |
| `api/main.py`             | `app/main.py`         | 直接替换，前者是 FastAPI 入口 + 异常处理器 + 生命周期 |
| `api/v1/auth_routes.py`   | `app/api/auth.py`     | 认证路由 → 重命名合并                                 |
| `api/v1/routes.py`        | `app/api/__init__.py` | 路由聚合 → 合并                                       |
| `api/v1/health_routes.py` | `app/main.py`         | 健康检查放 main.py 或单开 `app/api/health.py`         |
| `api/v1/__init__.py`      | ✗ 无需                | 新结构不用 v1 子包                                    |
| `api/agent_routes.py`     | `app/api/agents.py`   | LLM Agent 路由，单独文件                              |

### 📁 `core/` → `app/core/`

| `llm_module` 文件       | 目标位置                                           | 说明                                                         |
| ----------------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| `utils/config.py`       | `app/core/config.py`                               | 合并配置                                                     |
| `core/error_handler.py` | `app/core/exceptions.py` + `exception_handlers.py` | 异常定义拆到 `exceptions.py`，处理器拆到 `exception_handlers.py` |
| `core/data_pipeline.py` | `app/services/data_pipeline.py`                    | 数据管道 → 属业务逻辑，放 services                           |
| `core/extractor.py`     | `app/services/extractor.py`                        | 简历提取 → 业务逻辑                                          |
| `core/kg_builder.py`    | `app/services/kg_builder.py`                       | 知识图谱构建                                                 |
| `core/qa_engine.py`     | `app/services/qa_engine.py`                        | 问答引擎                                                     |

### 📁 `models/` → `app/models/` + `app/schemas/`

| `llm_module` 文件   | 目标位置                                           | 说明                                                 |
| ------------------- | -------------------------------------------------- | ---------------------------------------------------- |
| `models/schemas.py` | → `app/schemas/` 各文件                            | 拆入 `result.py`, `page.py`, `auth.py`, `jobs.py` 等 |
| `models/prompts.py` | `app/services/prompts.py` 或 `app/core/prompts.py` | Prompt 模板属 LLM 逻辑                               |

### 📁 `utils/` → `app/utils/` + `app/core/`

### 📁 其他文件

| `llm_module` 文件                                 | 目标位置                            | 说明         |
| ------------------------------------------------- | ----------------------------------- | ------------ |
| `agents/agent_coordinator.py`                     | `app/services/agent_coordinator.py` | Agent 协调器 |

------

**核心思路：** 目标结构已经设计好了基础骨架（用户、简历、岗位 CRUD），`llm_module` 带来的主要是 **LLM/AI 能力层**（Agent、RAG、KG、提取引擎、向量存储等），这些应该以新的 service 文件放入 `app/services/`，少数基础设施类（config/logger/database）合并到 `app/core/`。
