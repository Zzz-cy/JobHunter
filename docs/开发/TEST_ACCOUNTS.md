## 各账号典型演示路径

### 管理员（13800000000）
```
登录 → 数据分析(默认落点, 含新兴技能发现/技能转正)
     → 岗位发现 / 数据管理(一键同步所有库) / 监控后台
```
> 管理员登录后只出管理端导航，求职者页面（首页/找职位/AI 求职顾问等）手动输网址也会被带回数据分析。

### 求职者A（13900000001）
```
登录 → 我的简历(已有解析好的简历+技能标签)
     → 岗位推荐(有简历数据, 匹配效果直观)
     → 个人中心(收藏/求职进度有 mock 记录)
```

### 新用户（13900000002）
```
登录(空账号) → 上传简历 → LLM 解析(约1分钟) → 技能标签展示
            → 生成推荐 → 体验完整新用户旅程
```

## 注意

- 正式/公开环境部署后**立即修改这三个账号的密码**
- 求职者A 的简历来自 `03_mock_data.sql`（仅首次初始化时导入；一键同步不会重复导入 mock）
- **注销重放演示**：建议另建临时账号走「个人中心 → 账号设置 → 危险区注销 → 原手机号重新注册 → 重走引导」，不要注销种子账号。种子账号一旦注销，重跑 `02_seed.sql` 不会恢复手机号/邮箱（ON DUPLICATE KEY 命中 `user_code` 只更新昵称与密码），需手工 UPDATE 或重建库。注销留档机制见 `docs/开发/注销留档数据说明.md`。
