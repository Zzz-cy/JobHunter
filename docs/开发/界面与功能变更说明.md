# 界面与功能变更说明（引导建档 + 管理员视角）

> 状态：**方案已定稿、尚未开发**。本文只描述"用户能看到什么、能用什么"，供团队了解将要发生的变化。

---

## 一、顶部导航栏：按角色显示两套菜单

### 普通用户

| 现在（8 项） | 变更后（6 项） |
|---|---|
| 首页 / 找职位 / 岗位推荐 / 我的简历 / 数据分析 / 岗位发现 / AI 求职顾问 / 知识图谱 | **首页 / 找职位 / AI 求职顾问 / 岗位发现 / 知识图谱 / 数据分析** |

变化：**"岗位推荐"和"我的简历"从导航栏移除**，其余保留、顺序调整。

### 管理员

管理员登录后导航栏只显示管理端菜单（不再显示求职者菜单）：

```
数据分析 ｜ 岗位发现 ｜ 账号管理 ｜ 数据管理 ｜ 监控后台
```

配套变化：

- **管理员不再能看到求职者页面**：首页、找职位、职位详情、AI 求职顾问、岗位推荐、知识图谱、我的简历、个人中心——手动输入网址访问也会被自动带回数据分析页
- **登录后直接落在"数据分析"页**（数据分析的默认标签"新兴技能发现"就是技能转正工作台）
- **监控后台入口搬家**：原来藏在 AI 求职顾问页右上角的 📊 图标，移除，改为导航栏直接入口

> 说明：数据分析页保持两种角色共用——普通用户看统计图表，管理员额外看到"新兴技能发现"的勾选转正操作（现状即如此，不变）。

## 二、新用户首次登录：引导建档

**触发**：新账号第一次登录（每个账号只出现一次，已建档的老账号不会再弹）。

**界面**：全屏引导页（此页没有导航栏），一张表单、三个必填项：

| 字段 | 形式 |
|---|---|
| 期望城市 | 下拉选择（与找职位页城市选项一致） |
| 期望职位 | 文本输入 + 热门职位词快捷点选 |
| 期望薪资 | 下拉选择档位（10K 以下 / 10-20K / 20-30K / 30-50K / 50K 以上） |

**规则**：

- **没有"跳过"**，三项都必填才能进入系统
- 中途关掉页面没关系，下次登录还会回到引导页
- **填完自动跳转到"找职位"页，筛选器自动选好刚填的三项**：关键词=期望职位、城市=期望城市、薪资=期望薪资档——落地即看到符合期望的岗位列表

**不收集**：出生年月、性别、个人优势、学历等一概不要。

## 四、AI 求职顾问页

- 页面头部新增**"岗位推荐"按钮**，点击进入原岗位推荐页
- 岗位推荐页本身、推荐算法、推荐结果展示**全部不变**

## 五、新增页面：账号管理（仅管理员可见）

**入口**：导航栏"账号管理"。

**功能**：

1. **用户列表**：昵称 / 手机号 / 角色 / 状态（正常·已封禁）/ 注册时间 / 最后登录 / 是否已建档；支持按手机号或昵称搜索、分页
2. **设为管理员 / 收回管理员**：操作前二次确认；不能操作自己
3. **封禁 / 解封**：操作前二次确认；不能封自己
   - 封禁后：该账号无法登录（提示已被封禁），当时在线的会话下一步操作即失效
   - 解封后：立即恢复正常登录
   - 封禁只是开关，不填理由、不设期限

---

## 六、个人中心新增：注销账号（所有用户）

**入口**：个人中心 → 账号设置 → 底部"危险区"。

**流程**：点击"注销账号" → 弹窗**输入登录密码**确认 → 账号注销，自动退出到登录页。

**后果**（弹窗中会明确提示）：

- 账号无法恢复
- 简历、收藏、投递记录等不再可见
- 手机号 / 邮箱被释放，之后可以用原手机号重新注册（重新注册会重新走新用户引导）

---

## 七、账号状态一览

| 状态 | 登录 | 在线会话 | 恢复方式 |
|---|---|---|---|
| 正常 | ✅ | — | — |
| 已封禁 | ❌ 提示被封禁 | 下一步操作即失效 | 管理员解封，立即恢复 |
| 已注销 | ❌（账号不存在） | 立即失效 | 不可恢复；原手机号可重新注册 |
